# 视频封面

把**这条视频讲什么、画面里是谁**转成同一套杂志拼贴视觉，交付两张封面。

## 固定契约

- 唯一风格源是 `cover-editorial-collage`。先读 [原版风格摘录](references/editorial-style.md)，逐项落实，不混入其他封面 Skill 或通用电商模板。
- 默认直接生成最终图片，**不是只交模板或提示词**。只有用户明确要求提示词、模板或方案时才切换输出。
- 每次默认交付两张独立图片：**3:4 竖版**与 **16:10 横版**。建议尺寸分别为 **1536×2048**、**2304×1440**；比例是硬要求，像素尺寸可按用户需求调整。
- 两张采用同一主角、同一核心文案、同一隐喻与色盘；分别构图，禁止从一张封面直接裁切、拉伸或加边框冒充另一版。
- 人物来自本次视频或用户指定的真人参考。保留面部特征、发型、年龄感、衣着和可辨识细节；使用真人照片剪贴质感，避免替换成泛化 AI 人脸或插画人脸。
- 原版默认 `template`、X 封面 `5:2`、旧比例枚举及横版专用的 `avoid vertical poster`，都不是本视频版的输出规则。原版视觉语言完整保留，输出路由由本文件定义。

## 取得内容与人物

优先使用当前附件、用户指定文件和同一视频的上下文。只复用本条视频已确认的素材，不把上一条视频的标题、人物或效果数字带入。

| 已有输入 | 动作 |
| --- | --- |
| 视频与字幕／逐字稿 | 阅读稿件并抽帧，核对核心结论、人物及实际展示结果。 |
| 只有视频 | 抽帧看人物与演示；使用当前可用的音频／视频理解工具取得口播内容。静帧不等于已经听懂口播；口播仍缺失时，只询问字幕或核心讲解，不凭文件名猜主题。 |
| 口播稿／字幕与人物照片 | 阅读文本并查看照片，直接设计，不额外索取视频。 |
| 只有稿件，且要求真人出镜封面 | 一次性索取清晰人物照或视频截图；先保留文案，不虚构本人长相。 |
| 明确是无人物录屏／产品演示 | 用真实演示截图或核心物件替代人物，仍出两种比例，不硬添模特。 |
| 多人视频 | 优先指定主角，其次持续讲解或承担核心动作的人。关系不明确且影响封面时询问主角，不混合两人的五官。 |

有本地视频时，运行 [抽帧工具](scripts/inspect_video.py)：

```text
python "{SKILL_DIR}/scripts/inspect_video.py" "{视频绝对路径}" --out "{本次输出目录}/video-evidence" --count 8
```

`SKILL_DIR` 解析为本 Skill 所在目录；输入／输出路径解析为本机绝对路径。脚本需要 FFmpeg、FFprobe，只抽帧并记录时间戳，不转写口播、不识别人名、不自动选主角。

查看帧，选择 1～2 张面部清楚、表情自然、动作有信息量且没有字幕遮脸的图。均匀抽帧仅作初筛，必要时在相关时间点补帧。保存所选帧文件名与时间戳。真实界面素材只选择与视频主题相关且清晰的部分，避免把无关聊天或个人信息放上封面。

## 内容转为封面

在本次目录记录简短 `cover-brief.md`：

- 一句话核心观点或具体结果，注明对应字幕时间段／稿件段落。
- 主角参考文件与时间戳，以及发型、衣着、表情等保留项，不凭长相推断身份。
- A 层主标题：优先 2～6 个汉字／1～3 个英文词，承担一眼可读的视觉中心。
- B 层完整信息：短句准确补全主题；用户指定标题时保留原意与关键词，长标题移入 B 层，不把整段话挤成大字。
- C 层微文案：少量真实工具名、章节词或关键词；没有依据的期号、日期、收益、耗时和效果数据不填，装饰不靠乱码填充。
- 1～3 个主题视觉锚点、一个构图系统、一套色盘。主角计入锚点，避免塞满道具。

标题承诺必须由视频兑现。教程可用步骤纸条、真实界面碎片或手册隐喻；观点冲突可用撕裂报纸、批注或警示标签；生活成长可用真实场景、植物或阶梯。遵循原版主题映射，不把每条 AI 视频都画成机器人。

## 同一方案，两种专门构图

读 [双比例提示词](references/prompts.md)，填入本次已确认文案与素材角色。

| 版式 | 设计要点 |
| --- | --- |
| 3:4 竖版 | 纵向阅读动线；大标题与半身／近景人物错层，主体占据视觉中心，说明纸条居次级区域；避免把横版塞进竖框。 |
| 16:10 横版 | 横向阅读动线；人物与标题按视线、动作及锚点分区，纸带跨画幅串联内容；铺满横向画布，避免中心竖海报与空侧边。 |

布局是起点，不是固定左右模板。每条视频可在原版的杂志封面、撕纸横带、人物档案、手册剪贴等系统中选择。两版主次一致，但人物裁景、标题换行、纸片位置、锚点尺度按比例重排。

文字与脸部默认离边缘约 5%，底部预留约 10% 的关键内容缓冲；这是工作留白建议，不宣称是平台官方安全区。纹理和装饰可延伸至边缘。

## 生成与验收

1. 使用内置 `image_gen`，一次调用生成一款，先竖版再横版。横版继续传原始人物参考，可额外传竖版作配色／材质参考，但要求重新排版，不作为裁切目标。
2. 本地参考图先用图像查看工具打开。全部有本地路径时用 `referenced_image_paths`；含会话附件时用能覆盖目标的最少 `num_last_images_to_include`。两种引用方式择一，不同时传入；缺失素材先补齐。
3. 提示词首尾写明比例、方向、目标尺寸。工具未提供尺寸参数时只在提示词要求，最终以实际文件检测为准，不编造工具参数。
4. 每款仅生成一张完整非透明封面，不生成双图拼版、手机样机、展示墙或外围预览框。默认不索取 API key，不因尺寸控制切换到未选择的 CLI/API 路线。
5. 将工具返回的选定文件复制到本次项目目录，保留原字节，不覆盖用户素材。PNG 用 `.png`，JPEG 用 `.jpg`，不以改后缀冒充转码。新版本用 `-v2` 等后缀。
6. 逐张查看人脸一致性、中文逐字准确性、撕纸边缘、印刷颗粒、主题、文字遮挡和缩略图可读性。文件尺寸校验不代表视觉项已通过。
7. 使用 [双封面校验器](scripts/check_covers.py)，按 [尺寸配置](references/delivery-spec.json) 验证实际文件：

```text
python "{SKILL_DIR}/scripts/check_covers.py" --portrait "{本次输出目录}/cover-3x4.png" --landscape "{本次输出目录}/cover-16x10.png"
```

8. 比例不符、错字、人物漂移或主题跑偏时，用图像工具定点修正并保留原始人物参考；不默认用程序拼图或硬裁切替代图片编辑。每款最多两轮修正；仍未通过则标记具体未验收项，保存候选与检测结果，不将候选称为合格成品。

验收同时满足：3:4 和 16:10 实测比例；两张独立构图；内容有视频依据；人物一致；主标题无错字且一眼可读；原版撕纸、杂志、印刷质感鲜明。

## 交付

在用户指定目录，或工作区 `output/video-covers/{本条视频短名}/` 下保存：

- `cover-3x4.png` 与 `cover-16x10.png`（或真实 JPEG 扩展名）；
- `cover-brief.md`：内容、素材依据、实际尺寸、生成方式和人工视觉检查结论；
- `prompts.md`：两款最终提示词，便于复用与微调。

回复用本机绝对路径展示两张图，标注实测尺寸并简述已验收项。模板、提示词、接触表或测试色块均不替代最终封面。

可复用调用：

```text
使用 $视频封面，根据我上传的视频内容和视频里的人物制作封面。
完全沿用 cover-editorial-collage 的风格，生成 3:4 和 16:10 两张独立构图的成品。
自动提炼准确标题，保留人物辨识度，检查实际比例后展示并保存两张图片。
```
